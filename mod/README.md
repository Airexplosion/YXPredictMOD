# 观战名次预测（动态积分原生版 0.4.0）

本模组使用独立的本地积分。认证时长的扣款、发奖接口均未接入。首次创建存档赠送1000分，重启、重载不会再次赠送。

0.4.0 版本全面重构为游戏原生视觉画风（墨玉金边窗框、卷轴横幅、内凹暗潭、水墨分割线、原生字体），并将下注操作深度整合进角色手牌区域。

## 角色手牌区专属下注条（CharacterBetBar）

- 进入八人观战后，当前观战或查看的玩家下方手牌区会自动展现原生风格的专属下注条。
- **智能自动停靠（防遮挡）**：
  - 当角色拥有手牌或显示对方最后手牌时，投注条自动停靠在手牌上方（`y = 326`），下方手牌与上方卡牌槽均清晰可见；
  - 当显示居中仙命选择时，投注条自动停靠在仙命下方（`y = 48`）；
  - 手牌托盘为空时，投注条停靠在底部（`y = 76`）。
  - 用户也可以拖动投注条至任意位置，位置自动持久化。
- **投注条功能**：
  - 左侧：当前角色田忌赛马图标 + 彩色称号 + Elo分数 + 玩家名；
  - 中部：名次切换 `− [1~8] +`、实时买入倍率、投入积分输入框（与总览草稿互通）；
  - 调仓：未下注显示「下注」；已下注显示「加注 / 改猜」、「退半」与「清仓」；
  - 右侧：实时权益/预期返还预览、快捷「走势」按钮、「总览」按钮与极简「▾」折叠胶囊。

## 独立原生总览面板（PredictionPanel）

点击右上角「预测总览」或下注条右侧「总览」打开 1140×624 独立原生总览窗口。

- **零全屏遮挡**：
  - 绝无全屏阻挡蒙版，打开总览面板时，顶栏 8 位玩家头像、对局时间与底部交互依然可直接点击！
- **自由拖拽**：
  - 按住顶部卷轴横幅可将总览面板拖动到屏幕任意位置。
- **透视模式（Peek Mode）**：
  - 点击顶栏「透视」按钮，面板主体淡化至 18% 透明度且完全穿透鼠标射线（`blocksRaycasts = false`），无需关闭面板即可直接悬停查看下方的八格卡牌轴、对手手牌与对局动画！
- **折起模式（Minimize Mode）**：
  - 点击「折起」收缩为 56px 紧凑状态条，仅显示对局回合、交易状态与积分余额。

### 八人总览 Tab

- 八人总表展示全部 8 位玩家，拥有持仓的玩家自动置顶，当前观战的玩家显示鎏金行光晕（`SelfFlag`）；
- 每一行展示田忌专属图标、彩色称号、Elo、道心分/天梯分、名次、倍率、投入、调仓操作与权益结算；
- 支持在「详细数据」与「简洁模式」之间切换；
- 查看历史对局时支持「◀ 上局 / 下局 ▶」翻页。

### 局势走势 Tab

- 顶部 8 位玩家切换按钮 + 「跟随观战」按钮；
- 展开所选玩家的完整田忌档案卡片（称号、释义、赛季道心场次、连胜状态等）；
- 左右并排展示原生水墨深潭风格的「命元走势」与「命元占比走势」图表。

## 田忌赛马称号

- 真实Elo最高特等、第二上等、其余中等，最低牛马；最低距上一档至少400分为海马。
- 黑马：Elo后半玩家连续两胜且仍存活。
- 旋转木马：最近已记录赛季高点比起点高150且终点不高于起点。
- 顶栏头像挂签可通过总览面板右上角「顶栏马牌:开/关」随时切换。
