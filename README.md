# 名次预测 0.6.1 测试版

单人和多人使用同一个“名次预测”入口、同一个八人总览和角色下注条。未加入房间时使用原有单人积分账户；加入房间后显示服务端持仓与余额。单人已有余额不自动转到房间，两种模式都只能使用不可兑换的娱乐积分。

## 使用

仙府大厅选择对局，点原生“观战”旁的“名次预测”。大厅先选择加入、创建或匹配，按游戏原生观战确认进入后显示统一下注界面。已在实时观战时，下注条“总览”及 Ctrl+Shift+P 打开同一个界面，再点关闭。

选择最终名次，在投入框填写1–10000整数，点击投入、加注或换猜；退半、清仓只处理当前持仓。输入框直接读取当前文字，输入期间不会被刷新写回10。选手/对局切换时下注条重置草稿，避免拿另一人的旧数字提交。

多人进入同一局并加入相同六位房间号。房间有人加入时显示“游戏名（ID）加入房间”，房间底部显示成员。ID由客户端上报，服务器未独立核验官方账号所有权；公开成员标识与登录凭证分开，不暴露其他人的凭证。旧客户端未上报时用已有昵称和公开成员编号。

房主观战客户端负责同步结果，失联超过15秒暂停交易；最终八人的名次齐全后结算。联机赔率按每个选手的资金池投入比例浮动，正中者按比例分配；无人猜中退回该池本金。退半/清仓返退出部分原投入97%。单人仍使用原有Elo/局势报价与本地账本，统一界面不会迁移或重算旧账。

## 本次界面修改

0.6.1 恢复不透明暗夜底色、亮色文字、深色输入框和交替行底色；保留原生按钮轮廓并统一高对比配色。表头按列独立布局。

已合入上游0.3.13（3dcffe3）的头像悬停：默认马图，悬停或选中时显示角色；悬停范围包括头像、ID、称号及中间空白；重叠时选最近的一列。Ctrl+Shift+H切换相反模式，配置tianji.iconsOnFocus。旧alwaysCover不再影响新默认值。

- 移除多局、历史战绩与走势图界面，旧账目留在数据中用于结算，不删除已扣积分的持仓。
- 移除“差X分”和参考清仓长句，下注条只显示当前持仓。
- 操作按钮及输入框通过SDK的NativeControlStyle复用已初始化原生控件的外观，不复制游戏监听器。
- 左侧仙命按炼气至返虚固定角度环绕，同境界额外图标外扩；原生竖排名字改为MOD侧横排名字，原生图标本体仍接收原生悬停。布局使用独立缩放父节点，退出观战、战斗和停用时还原原父级/位置/缩放/名称显隐。环绕中心与半径尚待实际分辨率及角色画面验收。
- 移除旧单机面板/走势图与独立入口，保留仙府大厅入口及角色下注条总览。

## SDK

主仓库新增 `sdk/Yx.ModSdk/Unity/NativeControlStyle.cs`，说明见主仓库 `docs/dev/native-control-style.md`。Core不依赖Unity。此MOD的 `sdk-extensions/NativeControlStyle.cs` 是同一SDK源文件的字节一致兼容副本，编入MOD以兼容尚未更新的管理器SDK；不打包SDK DLL或游戏DLL。未来SDK发行包含该类型后可去掉源码兼容层，直接引用SDK。该MOD仓库可独立构建，不依赖另一个本机源码路径。
