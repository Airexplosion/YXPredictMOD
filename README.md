# 观战名次预测 0.5.2（联机娱乐积分测试版）

本版加入独立娱乐积分房间，并修复 0.4.0 的布局和交互。积分不可购买、兑换、转让认证时长；联机余额由房间服务保存，单机余额和旧存档保留，两者分开。

## 使用

1. 导入 `dist/local.yxp.predictionpoints-0.5.2.zip`，启用后重启游戏。
2. 在仙府大厅选择正在进行的对局，点击原生“观战”旁的“联机预测”；也可在实时观战时从总览进入。首次只显示“加入 / 创建 / 匹配”，再次点击入口关闭。
3. 点“加入”后输入六位房间号；点“创建”会先走所选对局原生观战，确认进入后创建房间。点“匹配”：只选择房主在线、未满、未结束、交易开放且已有投入的房间。按游戏原生观战确认进入对应对局后自动加入；不会自动投入。无权限、取消或90秒超时不加入预测房间。已在另一局时先通过游戏返回大厅。房主需要更新至0.5.2并同步游戏房间ID，其房间才支持随机发现。
4. 房主点“创建房间”，分享六位房间号；其他观众输入后加入。每个客户端身份首次获得 1000 娱乐积分。
5. 选择选手的最终名次和投入，修炼阶段可增持、退半、清仓或换预测；战斗期间暂停。整局结束、八人最终名次齐全后派奖。

默认服务器为 `https://auth.kaigua.vip/prediction`。管理器 MOD 配置的 `online.server` 可修改地址，`online.name` 用于首次注册昵称。身份凭证保存在管理器该 MOD 的数据中；不要删除或分享这个数据文件。

## 联机规则

八名选手各有独立资金池，每个池有第 1–8 名八个选项。参考赔率 = 该选手全部投入 / 所选名次投入，包含返还本金；最终回报以封盘后的资金池为准。正中者按投入比例分配资金池，无人猜中则退回该池本金；联机不采用单机的相邻名次奖励。整数尾数舍去。

退半、清仓返还退出部分原投入的 97%，余下 3% 消耗，不进入其他人的资金池。换预测先退出旧仓再投入新仓；余额不足时整笔回滚。每次操作最多投入 10000 分，每房间最多 32 人。

房主客户端同步当前回合、交易开关和最终名次。房主失联超过 15 秒暂停交易，重连同一局后恢复；离开房间不退回已投入积分。房主应持续观战至最终结果同步完成。房间不是官方战果验证系统，适用于互相信任的朋友；身份由本地凭证识别，未绑定官方账号。服务器没有充值或兑换接口。

## 界面修改

- 撤掉此前的仙命强制双列重排，恢复游戏原生布局；不再移动原生仙命图标或改写 basePos。旧版已经移动的实例需重启游戏恢复。
- 透视只穿透窗口主体，顶栏保留可点击的退出按钮。
- 下注条“走势 / 总览”加宽，文字内框留足空间，保留清晰文字；重复点击同一面板会关闭，切换按钮会转到对应页；打开窗口后仍可点到快捷按钮。
- 下注条折叠隐藏实际子控件；拖动后抑制误下注，提交时绑定所见的对局和玩家。
- 自动停靠读取手牌实际边界；没有安全空间时折叠。自定义拖动位置仍由用户选择。
- 总览和下注条通常放大到 125%，小屏按可用 Canvas 适配；统一字号、长文本省略和底部换行。
- 合入上游截至 `de78a72`（0.3.11）的圆形马牌、独立黑色描边、查看/悬停覆盖及 AI“电子马”称号。`Ctrl+Shift+H` 切换始终覆盖。

## 验证范围

120 项 C# 回归、9 项原生入口替身检查、官方 ILRuntime 核心及房间响应解码探针、Release 构建和 SDK 静态检查通过。房间服务 18 项测试覆盖双客户端 HTTP、资金守恒、重试幂等、旧报价、断线/重启、落盘失败回滚、名次与房主校验；部署后的公网 HTTPS 双客户端与原认证服务健康检查通过。

0.5.1 曾实测旧大厅入口、面板、空匹配和原生确认/取消；0.5.2 的观战旁入口、精简菜单及文字/开关修复尚未实机验收。本次检测到用户游戏正在运行，未操作或覆盖当前安装档。本包是测试版，未修改正式 Release 更新清单。
