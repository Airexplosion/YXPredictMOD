# 弈仙牌观战名次预测 MOD (v0.4.0 原生重构版)

已实现积分版完整流程：实时八人观战 → UID 查询 Elo → 按公开局势动态报价 → 每轮买入/增持/减半/清仓/换预测 → 逐人结算 → 持久化余额和持仓。
本次 0.4.0 版本进行了游戏原生视觉重构，彻底告别旧版突兀的暗黑平铺方块界面，将下注交互无缝融入游戏原生场景。

认证时长接口按当前需求留空，不读取、扣减或增加加载器认证时长。首次积分 1000，操作说明见 [mod/README.md](mod/README.md)。

## 0.4.0 原生视觉与交互特性

1. **游戏原生视觉深度融合（NativeTheme）**：
   - 提取并复用游戏 `ScoreboardPanel`、`ReadyLayer` 及 `TalentSelectionPanel` 原生九宫格墨玉金边窗框、云纹卷轴横幅、内凹暗潭衬底、鎏金行光晕（`SelfFlag`）、水墨毛笔分割线以及原生 TextMeshPro 字体材质。
2. **角色手牌区专属下注条（CharacterBetBar）**：
   - 将单人投注条直接下放至当前观战/选中角色的手牌区域（`每个投注的按钮放在对应角色下方的手牌的那个地方`）。
   - **智能避让与自动停靠**：实时检测手牌与天赋状态（`BetBarAutoY`）。有手牌/对方手牌时停靠在手牌上方（`y = 326`），居中天赋时停靠在下方（`y = 48`），空手牌区停靠在底部（`y = 76`），绝不遮挡手牌、卡牌槽与游戏交互。
   - 包含田忌马牌图标+称号+Elo、名次调节 `− [1~8] +`、实时赔率、投入积分（与总览共用草稿）、原生操作按钮（`下注`/`加注`/`改猜`、`退半`、`清仓`）、实时权益/返还预览、快捷`走势`与`总览`切换、以及 `▾` 极简折叠胶囊。支持拖动保存。
3. **独立原生总览面板（PredictionPanel）与防遮挡架构**：
   - **零全屏遮挡**：彻底移除全屏阻挡蒙版，打开总览面板时，顶栏八位玩家头像及底部控制区域仍 100% 可正常点击与切换。
   - **自由拖拽**：按住顶部卷轴横幅可将总览面板拖动到屏幕任意位置，自动边界吸附防越界。
   - **透视模式（Peek Mode）**：点击顶栏「透视」按钮，面板主体淡化至 18% 透明度且完全穿透鼠标射线（`blocksRaycasts = false`），无需关闭面板即可直接悬停查看下方的八格卡牌轴、对手手牌与对局动画！
   - **折起模式（Minimize Mode）**：点击「折起」收缩为 56px 紧凑状态条，仅显示对局回合、交易状态与积分余额。
4. **田忌赛马全链路融合**：
   - 总览面板八人表格每一行直接内嵌田忌赛马高精度专属图标、彩色称号（特等马/上等马/牛马/海马/黑马）、旋转木马标签、公开Elo及道心分/天梯分。
   - 走势图界面展示该玩家的完整田忌档案卡片与赛季数据。
   - 保留顶栏头像马牌显示，并可通过顶栏「顶栏马牌:开/关」随时切换。

## 安装

将 `dist/local.yxp.predictionpoints-0.4.0.zip` 导入弈仙牌 MOD 管理器并启用。

## 构建与验证

Windows PowerShell，项目根目录：

```powershell
# 第一次获取固定版本 SDK（后续会逐文件复核 Git blob 哈希）
./scripts/restore-sdk.ps1

# 第一次或游戏更新后，从自己安装的游戏生成引用
./scripts/prepare-game.ps1 -GamePath 'C:\Program Files (x86)\Steam\steamapps\common\YiXianPai'

# 流程测试 + ILRuntime解释器执行 + 完整游戏构建 + 静态校验 + 打包
./scripts/build.ps1

# 同时输出模拟八人局流程；演示数据不写真实积分存档
./scripts/build.ps1 -Demo

# 没有游戏时，只测核心逻辑并构建 Core DLL（无游戏面板、不打包）
./scripts/build.ps1 -CoreOnly
```

- 官方 ILRuntime 2.1.0 解释器探测通过（`INTERPRETER PASS`）。

- 官方 SDK `yx-patch check --warn-as-error` 静态检查 0 错误、0 警告。
- 打包生成 `dist/local.yxp.predictionpoints-0.4.0.zip`。
