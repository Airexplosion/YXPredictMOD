# 0.8.0 网页观战下注与 Elo API

网页入口 `https://duma.kaigua.vip`，Elo API `https://elo.kaigua.vip`，两者位于同一台服务器。Elo域名不再提供前端页面；原IP站点与其他服务保留。

网页首页为仙府观战厅，同一时间只展示一场公开赌马；其余房间只在游戏内开放，不允许通过网页接口绕过。当前公开局结束后，新建公开房间可接替网站展示。无需登录即可查看八人战况、冠军倍率、基础倍率与修正系数、命元曲线和逐轮文字记录。战况由房主MOD同步；房主离线时明确显示并暂停交易，不伪造赛事。

使用原有YG登录。已有绑定账户直接复用同一马币、持仓和结算，不额外复制余额。没有MOD账户的身份可主动开通一个网页账户，初始1000马币，一身份一次；可沿用每日200签到。用户自己无需打开游戏即可选局、下注、减半、清仓和等待整局派奖。未绑定的MOD账户仍自动上榜。

网页交易复用服务端同一规则：仅押冠军、第10回合封盘、退出/淘汰选手禁投、第一/二/三名返还锁定额度的100/25/10%，基础倍率乘以下回合冻结投注修正系数。客户端保存未确认操作ID，网络失败先确认上一笔，不能无意重复扣款。

新版MOD向同一房间同步公开的命元/胜负数据；服务端按UID重排，逐回合保留最多100帧。从原生公开BattleResult同步桌面usedCards、名称、双方与明确胜者；镜像战单列，不读取或广播手牌。出现战果的回合立即封盘，拒绝矛盾战果/牌桌；支持跟随最新回合或回看。旧版本房主没有新增字段时仍兼容，网页明确等待战况。Elo改成同一域名一次查询完整八人，成功缓存5分钟、缺失/失败30秒，Unity主线程分帧解析与四任务上限保持。原始UID完整种子和已确认的新复盘接续计算，详见 `server/elo/README.md`。

验证包含核心/服务端/ILRuntime/Release静态检查；浏览器在本机隔离数据中通过实际YG服务登录、绑定、签到、房间大厅、八人卡片、37马币数字输入、共享MOD账户扣款、命元帧更新、第10回合封盘、终局派奖及桌面/390px手机无溢出。未启动或附加游戏，不把离线网络替身视为实机验收。生产验证不创建测试马币账户。

旧16位数据密钥由用户向原作者询问中，尚未接入最新哈希数据；不因此声称当前历史覆盖完整。

上游PR #3已经合并；之后0.7.13为整合发布，0.7.14唯一新增运行时代码是默认保留人物头像、悬停显示马图。已取当前上游6b826381并同步此设置。新增原生读取基于当次提取热更c65e2c4ac6d5；公开牌组字段通过缓存FieldInfo与非泛型IList边界复制，不在热更域增加List<int>实例化；补充官方ILRuntime探针覆盖反射/CLR集合读取与不修改源集合，静态检查0error/0warning。

Elo生产自动更新已成功完成：原始种子115567人，接续18084局后117441人；不宣称全服或无间断覆盖。以/api/v1/status实际源时间为准。生产网页匿名HTTPS/素材/CSP/390px布局回读通过；部署备份核对27账户、26房间和原马币记录未被重置。
