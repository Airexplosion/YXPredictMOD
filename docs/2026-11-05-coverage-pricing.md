# 冠军竞猜整盘报价校准

最近两场保存的首轮报价中，八名选手配成相同冠军奖励额度，第一、第二、第三合计返还 135%，总投入却更低，理论保底收益约 10%。额外三倍全猜会进一步放大该问题。

新冠军房间保存 `coverageVersion:1`。报价在基础倍率、冻结的人气系数和整点加成之后，统一按比例向下校准。两分钟窗口待确认及开放期间计入三倍；结束后下一次状态同步按普通奖励校准。非整点房间按原首回合三倍规则计算。窗口跨战斗、同回合刷新、选手顺序变化、淘汰人数变化均走相同校验。普通竞猜使用同一套报价；三倍依然是这一报价的三倍，并保留锁定规则。

校验不是只看八人平均投入：把最终奖励额度升序排列，最差结果为最低额度的 100%、次低的 25%、第三低的 10%。有序额度可分解为后缀阶梯，因此分别检查覆盖全部、少一人、少两人的最高倍率组合即可覆盖任意比例。按剩余人数取对应前三返还权重，必要时同比例压低报价，使这类组合的最优保底返还不超过投入的 98%。向下取整后不再抬回 1.01 倍，普通竞猜部分报价可能低于 1 倍。

同一钱包新增竞猜时，连同已有未结算持仓一起检查：若所有仍可能的最终结果都能返还至少当前投入成本，拒绝本次操作。该校验位于原事务内，批量命令后续一笔失败时，前面的扣款、持仓与回执一并回滚。金额取整、幂等请求与到账统计沿用原规则。

适用边界：新局生效，已有房间不迁移，已经锁定的返还额度不重算。校准防止同一报价下分散覆盖产生确定利润；同钱包另有跨回合持仓校验。它不是多账号关联风控，不能承诺消除多人跨回合协作、撤回获利或公共战况变化带来的所有获利机会。

撤回估值继续使用排除本人贡献的独立单位，避免报价统一缩放本身制造撤回收益。网页明确展示校准后的最终倍率，机器人和联网客户端读取同一服务端报价。单机本地计算没有在此次服务端变更中改动。

验证：257 项 Node 测试通过，包含 2～8 名剩余选手、普通/三倍、随机整数投入、仅覆盖六人、八钱包三倍全猜全部前三排列、同回合刷新、重启后锁定收益、跨回合组合及批量回滚。原撤回、网站交易、QQ 注册/绑定、排行榜与旧房间结算测试同步核对新报价。
