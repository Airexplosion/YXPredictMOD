# 持续观战、完整通知与最高均分选场

用户报告机器人观战仍出现离线和等待房主提示。实际日志显示同步400被当作观战连接故障，触发退房重进。只读连续观战抓取进一步复现：原生扣命元lifeDamage带正负方向，旧校验拒绝负数；10帧真实公开数据只有2帧通过。修正有符号校验与规范化换边后，10帧全部通过，不修改资金结果。

后台同步失败、展示注解校验失败与大厅刷新失败不再关闭游戏观战连接。全局GameStatus与单桌BattleResult分离，避免混合新旧名次；状态先上传，头像/牌阵补读随后进行。大厅刷新不在连接中阻塞长时间重试。健康报告不续期报价，数据仍必须在15秒内有效，第10回合封盘不变。

回合通知等八人资料和应有对阵齐全再领取，未识别角色、未知牌或缺图时不发残缺合并消息，去除45秒超时放行。首轮尚未公开的内容如实标注，退出角色展示最后完整公开牌阵，末轮在资金结算后继续短暂收齐。结算结束语和逐人收益继续保留。

新开局固定在原生均分至少6000、第1至2回合的候选中选择均分最高者；同分按开局时间从新到旧，最后按房间ID稳定排序。只影响新场。

验证：113项Node、30项Python、51项机器人及类型检查；真实只读入场一次连续读取10帧，期间模拟两次后台拒绝没有重进，最大采样间隔2.43秒，退出后确认账号空闲，没有生产写账或群测试消息。真实帧再经内存房间服务重放10/10通过。北京时间11月2日15:00整点采用新规则开盘，原生均分7418，观察到八人资料到齐、有效状态持续刷新；一次部署重启引起的后台502没有重建游戏观战连接。原Steam/道心/战绩服务PID及重启次数保持。
