# 整点公开观战与 WHITE

`/马币`现支持自动开户：未绑定游戏账号的QQ也能先开通1000马币并查询，但不能下注。完成账号认证后，再次查询或首次下注会自动核对同UID的游戏钱包，关联到同一YG身份；早期开通的QQ余额同步过去，不再发放一次开户余额。账号认证到期仍可查询自己的余额，下注需续期。封禁、撤销和已归属其他身份的账户不会自动转移。

自动关联由认证服务器验证UID哈希，签名票只含域隔离的QQ/游戏身份引用，不包含原始QQ、UID或隐私密钥。候选UID列表只通过专用机器人接口传递；若候选集变化，刷新证明后重试。QQ待结算持仓保留原账户，结算后再同步空闲余额；同步记账与绑定、初次开户原子落盘，重复命令不重发1000。已同步的旧QQ钱包不再触发低余额救济；签到目标同时更新，原签到日期保留。

服务端功能，兼容现有0.8.0客户端；不改已发布安装包和更新目录。

## 开盘与结算

北京时间每个整点的前5分钟寻找一场刚开始的公开八人对局；02:00至06:00（包含两端）不开新场。对局必须在第1至2回合，原生平均段位分严格超过3000。天梯与道心列表均搜索；这个门槛不使用Elo。无合格对局、账号被其它采集器占用或当前公开场未结束时跳过，不打断原有观战。

网站仍只展示一场公开赌马，其余房间留在游戏内。每整点最多开一次，重启不重复；尚未结算的整点场优先恢复，报价模型和马匹称号继续使用本局锁定值。

普通房间维持原倍率。整点场在正常“基础倍率 × 本轮冻结的投注修正”之后再乘1.15；正常上限50倍先执行，专场最高57.5倍。只猜冠军，第一/第二/第三返还锁定权益的100%/25%/10%。第10回合起停止全部交易；若官方启用延迟观战，实际公开列表已经到第10回合也会封盘，不能利用较早的播放画面继续投注。退出角色不接受新投注。

## Linux观战

`server/observer`使用专用账号已有的、由原采集服务续期的票据。它不注册账号、不启动Steam、不刷新或导出票据、不踢掉其它会话。加入前检查账号空闲，并持有原采集器同名的`public-observer-<sha256(uid)前20位>.lock`独占锁。锁文件须预先存在。退出时调用本次观战会话的正常离开并检查账号已空闲；清理失败会记录并阻止后续强占。

每次连接先读取官方服务器配置：普通观战使用原生GameStatus请求；官方启用延迟观战时只按原生快照及命令时间播放，不申请实时、裁判、好友等额外权限。名单必须与独立公开大厅名单的UID集合完全一致，不靠匿名序号、头像或位置猜身份。

只投影公开数据：昵称、档位、命元、胜负次数、公开战斗双方、上轮已使用牌及明确的胜者。忽略PrivateData、手牌、抽牌候选等；内部Elo仅用于冻结报价，不出现在公开接口或群消息。卡名由现有公开卡牌目录更新，未知卡明确标注，不猜牌。卡牌标签是运行数据，不提交本机游戏引用或反编译材料。

Python使用独立虚拟环境，依赖见`requirements.txt`。配置文件0600，复制`config.example.json`后填写专用观察密钥和本机票据路径；该密钥只授予`/ops/hourly`。提供的systemd单元以只读方式访问原采集目录，原Steam及采集服务无需重启。

```sh
python3 -m venv /opt/yx-duma-observer/venv
/opt/yx-duma-observer/venv/bin/pip install -r requirements.txt
/opt/yx-duma-observer/venv/bin/python update_card_names.py --output /var/lib/yx-duma-observer/card-names.json
/opt/yx-duma-observer/venv/bin/python main.py --config /etc/yx-duma-observer.json --once
```

正式运行使用`yx-duma-observer.service`。程序每15秒检查一次调度；入场后持续读取公开状态并同步，全部结果确认才派奖。观战断线后15秒内服务端自动暂停交易；恢复时重新校验名单及整局ID，数据缺失不编造结果。若房间已被官方回收、结果不完整，保留资金和未结算持仓供维护者核对，不另开新场掩盖它。

## 工具群

WHITE沿用现有OneBot连接，仅在工具群启用。每条用户命令都向原认证服务器获取60秒内有效、且不超过认证到期时间的专用签名票据；核对认证有效、封禁和当前绑定。主体计算与YG网页登录相同，复用已选择的网页/MOD马币账户。未开账户者首次有效下注才开通一次。已下注后的派奖不受后来认证到期影响。

| 命令 | 功能 |
| --- | --- |
| `/赌马` | 本场公开战况与玩法 |
| `/下注 1 100` | 向1号选手投入100马币，只猜冠军 |
| `/选手 1` 或 `/选手 完整昵称` | 查询指定选手的公开牌桌及战果 |
| `/马币` | 同一身份的可用马币与累计收益 |
| `/退半 1`、`/清仓 1` | 封盘前出售指定持仓 |
| `/赌马 查单` | 核对上一笔群内交易回执 |

交易使用原始群消息ID作为持久幂等键，跨对局重发也不会再次扣款；不确定的网络结果只重试同一ID。QQ成功回执后才确认用户已收到交易结果；未确认时，新下注先返回旧回执并说明本条未执行。禁止通过复制新消息盲目重投。

开盘和每回合战况使用合并消息，待当轮完整或进入下一轮后发送，结算另通知。通知队列落盘、带租约，QQ确认成功后再标记已发；QQ发送成功但确认丢失时，可能重复通知。该重试不会触发交易或派奖。未发送虚构开盘消息作为验收。

认证适配器保留在加载器私有仓库。公开MOD仓库只包含独立房间服务、专用权限接口及观察程序，不含管理员密钥、认证数据库或登录票据。
